1.9 Method Signatures

  • A method is a named block of code that runs when it's called. Use one when code repeats.
  • Procedural abstraction: you can use a method by knowing what it does, without knowing how.
  • Parameter = variable in the method header. Argument = value you pass in the call. In add(3, 4), 3 and 4 are arguments; in add(int a, int b), a and b are parameters.
  • Signature = method name + ordered list of parameter types. calc(int, double). Return type and parameter names are not part of it.
  • Arguments must match the parameters in number, order, and type. An int argument can go into a double parameter, but not the reverse.
  • Call by value: the parameter gets a copy of the argument. Changing the parameter inside the method doesn't change the caller's variable.
  • Overloading: same name, different signatures (different number, types, or order of parameters).
  • Flow of control: a call jumps into the method, runs all of it, then comes back to the line right after the call.
  • void methods return nothing. Non-void methods return a value of the return type, which you should store, print, or use.
TrapChanging only the return type is not overloading. int f(int x) and double f(int x) have the same signature, so that's a compile error.

1.10 Calling Class Methods

  • Class methods (also called static methods) have static in the header and belong to the class, not to an object.
  • Header pattern: public static returnType name(parameters)
  • Call them with the class name: ClassName.method(). Inside the same class, the class name is optional.
  • You can't print or store the result of a void method: System.out.println(sayHi()); is a compile error if sayHi is void.
  • The variable that receives a return value needs a compatible type: int x = methodReturningDouble(); is an error.

1.12 Objects: Instances of Classes

  • A class is the blueprint; it defines a new type. An object is one specific instance of a class.
  • Dog pet = new Dog(); → Dog is the class, pet is the object (instance).
  • A reference-type variable holds a reference (think: memory address) to the object, or null.
  • Attributes / instance variables = what an object knows (name, age). Behaviors / methods = what it can do.
  • Inheritance: a subclass extends a superclass and gets its attributes and behaviors. class Poodle extends Dog → Poodle is the subclass. Every class is a subclass of Object.
Trap"An instance of the pet class is Dog" has it backwards. The object is an instance of the class. Read these answer choices slowly.

1.13 Creating & Initializing Objects

  • A constructor builds a new object and sets its attributes. It has the same name as the class and no return type.
  • Call it with new: Movie m = new Movie("Up", "Docter", 8.3);
  • Overloaded constructors differ in number, type, or order of parameters. A no-argument constructor takes nothing: new Cat().
  • Arguments must match one constructor's parameter list in number, order, and type. If none matches, it won't compile.
  • Arguments are passed by value, same as methods.
public Cat()                                 // no-arg
public Cat(String c, String b, boolean h)    // 3 args

new Cat();                          // ✓
new Cat("orange", "Tabby", false);  // ✓
new Cat("Shorthair", true);         // ✗ no 2-arg constructor
Cat("orange", "Tabby", false);      // ✗ missing new

1.14 Calling Instance Methods

  • Instance methods (no static) are called on an object with the dot operator: myParty.inviteFriend();
  • You need an object first. Cat.meow() doesn't work if meow is an instance method.
  • Calling a method on null → NullPointerException (run-time error).
  • Arguments must match the signature. Parentheses are required even with no arguments.
  • Do something with a non-void method's return value: store it, print it, or use it in an expression.

1.15 Strings heavy

  • Create with a literal "hi" or new String("hi"). String is in java.lang.
  • Strings are immutable. Methods like substring return a new String; the original never changes.
  • Indexes go from 0 to length() - 1. Going outside → IndexOutOfBoundsException.
  • + concatenates. A primitive joined with a String becomes text. Evaluated left to right.
  • Compare contents with .equals, not ==.
